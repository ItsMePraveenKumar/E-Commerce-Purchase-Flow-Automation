E-Commerce-Purchase-Flow-Automation
Project Run Guide

==================================================
1. PROJECT REQUIREMENTS
==================================================

Required:
- Windows
- Python
- PyCharm (recommended for this guide)
- Google Chrome
- Internet connection

This project uses:
- Python
- Selenium
- PyTest
- OpenPyXL

==================================================
2. OPEN THE PROJECT
==================================================

1. Extract the project ZIP.
2. Open PyCharm.
3. Select:
   File -> Open
4. Select the project root folder:

E-Commerce-Purchase-Flow-Automation-master

5. Open the PyCharm Terminal.

Make sure the terminal is inside the project root.

Example:

E-Commerce-Purchase-Flow-Automation-master>

==================================================
3. CHECK PYTHON
==================================================

Run:

python --version

The tested setup for this project is:

Python 3.14.5

The project also runs successfully with this Python setup.

==================================================
4. INSTALL REQUIRED PACKAGES
==================================================

Run:

python -m pip install selenium pytest openpyxl

Why:
- selenium -> browser automation
- pytest -> test execution
- openpyxl -> Excel test data

Using "python -m pip" is recommended because it installs
packages into the Python environment being used by "python".

==================================================
9. WHY USE "python -m pytest"?
==================================================

Instead of:

pytest Tests/test_e2e.py

use:

python -m pytest Tests/test_e2e.py

This avoids problems where the "pytest" command is not
available in the Windows PATH.

The project was successfully run using:

python -m pytest -v

==================================================
12. TROUBLESHOOTING
==================================================

Problem:
'pytest' is not recognized.

Solution:

python -m pip install pytest

Then:

python -m pytest -v

--------------------------------------------------

Problem:
FileNotFoundError for pythondemo.xlsx.

Cause:
pythondemo.xlsx is missing from the project root.

Solution:
Put pythondemo.xlsx in the project root and use:

book = openpyxl.load_workbook("pythondemo.xlsx")

--------------------------------------------------

Problem:
Excel file cannot be opened.

Cause:
The file may not be a real .xlsx file.

Solution:
Create a valid Excel workbook with:

TestCase | firstname | lastname | gender
TestCase 2 | Vikash | Dwivedi | Male

--------------------------------------------------

Problem:
Chrome/WebDriver does not start.

Check:
1. Chrome is installed.
2. Internet connection is available.
3. Selenium is installed:

python -m pip install selenium

--------------------------------------------------

Problem:
A test fails after the website changes.

Possible cause:
The automation depends on website elements, locators,
text, and page behavior.

Check the Selenium error and the affected Page Object.
